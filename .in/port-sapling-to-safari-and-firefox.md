# Port Sapling to Safari and Firefox

## Task

Port the Sapling browser extension to Safari and Firefox, keeping feature
parity with the Chromium extension.

## Checklist

- [ ] Audit the current Manifest V3 implementation for Safari and Firefox compatibility.
- [ ] Add the required Safari Web Extension packaging and native host project.
- [ ] Add and test the Firefox extension manifest and browser-specific adaptations.
- [ ] Verify popup behaviour, permissions, icons, storage, and versioning in both browsers.
- [ ] Document build, local-install, signing, and release steps for Safari and Firefox.

## Done when

The extension can be installed and used successfully in Safari and Firefox,
with documented repeatable build and release commands.
