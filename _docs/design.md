# Sapling — design

Sapling is quiet utility chrome: the interface should stay out of the way of the writing.

## Tone

- British English in user-facing copy (sentence case).
- Calm, practical labels over “marketing” language.

## Extension surfaces

### Popup

- Compact, narrow layout.
- One primary action: **Open Sapling**.
- Subtle footer attribution link: “A Danny Hope product”.

### Full app (tab)

- The app UI lives in `v2/` and should remain focused on editing + history.

## Icon

- Toolbar icon is a **neutral glyph** on a **transparent** background.
- Colour: mid-grey `#7B858A`.
- Simple sprout mark (readable at 16px); no square tile background.
